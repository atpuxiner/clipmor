1、概述

本隐私政策适用于 Clipmor，一款轻量极简、低资源占用的 Windows 剪贴板增强工具。我们遵循一个基本原则：您的数据属于您自己。Clipmor 无账号、无登录、无任何在线服务，所有功能均在本地完成。

2、我们收集的信息

Clipmor 不收集、不存储、不上传任何个人身份信息。

数据类型是否收集说明
个人身份信息（姓名、邮箱、电话等）否无账号体系，无需注册登录
剪贴板内容仅本地仅保存在本机 SQLite 数据库
待办清单内容仅本地仅保存在本机 SQLite 数据库
设备信息、使用统计、崩溃日志否无遥测、无统计、无上报

3、数据存储位置

所有剪贴历史、备忘录文本、图片与程序配置仅保存在您的本地计算机，存放于系统 %LOCALAPPDATA%\Clipmor 目录（数据库文件 clipmor.db 与图片目录 clipmor.imgs）。数据不会上传到任何服务器。

4、剪贴板权限说明

软件读取剪贴板内容仅用于将复制内容保存为本地历史记录。读取到的全部内容只写入本机磁盘，不会向外发送。

5、网络访问

Clipmor 默认不会主动发起任何网络请求，无数据上报、无遥测、无统计收集，可完全离线使用。

6、开机自启与注册表

开机自启为可选项，默认关闭，由您手动开启。开启后仅写入当前用户的注册表节点（HKCU），不修改系统级配置（HKLM）；关闭或卸载程序时会自动清理对应注册表项。

7、数据的删除与清理

您可在应用内随时清除不需要的记录（清除未置顶记录或清空全部记录），删除后不可恢复。卸载程序时可勾选删除用户数据（默认不勾选）。

8、数据安全

本地数据库采用加密存储，防止数据被未授权访问；程序不与外部服务器通信，降低数据泄露风险。由于数据仅存于您的设备，请您妥善保护系统账户与磁盘。

9、未成年人

Clipmor 不收集任何个人数据，不包含广告与内购，适合所有年龄段用户使用。

10、政策的变更

如本政策发生变更，我们将更新本页面顶部的「更新日期」并重新发布，恕不另行单独通知。

1. Overview

This privacy policy applies to Clipmor, a lightweight, low-resource Windows clipboard enhancer. Our principle is simple: your data belongs to you. Clipmor has no account, no login, and no online services; everything runs locally.

2. Information We Collect

Clipmor does not collect, store, or upload any personal information.

Data TypeCollectedNotes
Personal identity info (name, email, phone, etc.)NoNo account or login required
Clipboard contentLocal onlyStored in a local SQLite database
Todo list contentLocal onlyStored in a local SQLite database
Device info, usage stats, crash logsNoNo telemetry, no tracking, no reporting

3. Data Storage

All clipboard history, memo text, images, and settings are stored only on your local computer under %LOCALAPPDATA%\Clipmor (clipmor.db database and clipmor.imgs folder). Nothing is uploaded to any server.

4. Clipboard Permission

Clipboard access is used solely to save copied content to local history. All captured content is written only to local disk and is never sent anywhere.

5. Network Access

Clipmor makes no network requests by default — no reporting, no telemetry, no statistics. It works fully offline.

6. Auto-Start & Registry

Auto-start on boot is optional and off by default. If enabled, it writes only to the current user's registry key (HKCU) and never modifies system-level settings (HKLM). The entry is automatically removed when disabled or on uninstall.

7. Data Deletion & Cleanup

You can clear records anytime in the app (clear unpinned records or clear everything); deleted data cannot be recovered. When uninstalling, you can check the option to delete user data (unchecked by default).

8. Data Security

The local database is encrypted to prevent unauthorized access, and the app never communicates with external servers. Since data stays on your device, please protect your system account and disk.

9. Children

Clipmor collects no personal data, contains no ads or in-app purchases, and is suitable for all ages.
